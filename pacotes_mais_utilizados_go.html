📦 Pacotes Mais Utilizados em Go

Um guia completo dos pacotes essenciais para desenvolvimento em Go

🎯 Pacotes da Standard Library (Mais Comuns)

fmt

Formatação de entrada e saída. Um dos pacotes mais usados.

fmt.Println("Hello, World!")
fmt.Printf("Value: %d", 42)
Altíssimo Uso

strings

Manipulação de strings e operações com texto.

strings.Contains("hello", "ell")
strings.Split("a,b,c", ",")
Altíssimo Uso

strconv

Conversão entre strings e tipos numéricos.

strconv.Atoi("123")
strconv.Itoa(123)
Alto Uso

os

Interface com o sistema operacional.

os.Getenv("PATH")
os.Open("file.txt")
Alto Uso

io / ioutil

Operações de entrada/saída.

ioutil.ReadFile("file.txt")
io.Copy(dst, src)
Alto Uso

net/http

Cliente e servidor HTTP.

http.Get("https://example.com")
http.ListenAndServe(":8080", nil)
Altíssimo Uso

🌐 Desenvolvimento Web & APIs

gin-gonic/gin

Framework web rápido e minimalista.

go get -u github.com/gin-gonic/gin
Muito Popular

gorilla/mux

Roteador poderoso para HTTP.

go get -u github.com/gorilla/mux
Popular

jwt-go

Implementação de JSON Web Tokens.

go get -u github.com/dgrijalva/jwt-go
Muito Usado

cors

Middleware para habilitar CORS.

go get -u github.com/rs/cors
Comum

💾 Banco de Dados & ORMs

database/sql

Interface genérica para bancos SQL.

sql.Open("postgres", "connection string")
Essencial

lib/pq

Driver PostgreSQL para Go.

go get -u github.com/lib/pq
Padrão

go-sqlite3

Driver SQLite3 para Go.

go get -u github.com/mattn/go-sqlite3
Popular

gorm

ORM para Go.

go get -u gorm.io/gorm
Muito Usado

redis

Client Redis para Go.

go get -u github.com/go-redis/redis
Comum

🛠️ Utilitários & Ferramentas

sync

Primitivas de sincronização (WaitGroup, Mutex).

var wg sync.WaitGroup
var mu sync.Mutex
Essencial

time

Funções para manipulação de tempo.

time.Sleep(2 * time.Second)
time.Now().Format("2006-01-02")
Muito Usado

encoding/json

Codificação e decodificação JSON.

json.Marshal(data)
json.Unmarshal(bytes, &result)
Altíssimo Uso

flag

Parsing de flags de linha de comando.

flag.String("name", "", "description")
Comum

crypto

Funções criptográficas.

crypto/rand
crypto/md5
crypto/sha256
Importante

🧪 Testes & Qualidade de Código

testing

Pacote para escrever testes unitários.

go test -v ./...
Obrigatório

testify

Kit de ferramentas para testes.

go get -u github.com/stretchr/testify
Muito Popular

mock

Framework para mocking.

go get -u github.com/golang/mock
Útil

🚀 Desenvolvimento Moderno

context

Para cancellation e timeouts em operações.

context.WithTimeout(ctx, 5*time.Second)
Essencial

go modules

Sistema de gerenciamento de dependências.

go mod init
go mod tidy
Obrigatório

viper

Gerenciamento de configuração.

go get -u github.com/spf13/viper
Popular

cobra

Framework para CLI applications.

go get -u github.com/spf13/cobra
Muito Usado

💡 Dica: Use go doc para explorar a documentação de qualquer pacote diretamente no terminal.

📚 A Standard Library do Go é extremamente rica - sempre verifique se já existe uma solução nativa antes de buscar pacotes externos!
